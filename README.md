# Travel-Log

Persönliches Flug-Logbuch seit 1985 als einzelne, statische Seite (`index.html`, DE/EN).
Gehostet über GitHub + Cloudflare Pages (kein Build-Befehl, Ausgabeordner: Hauptverzeichnis).

Veröffentlichen: `./publish.sh "Beschreibung"`

Der Ordner `privat/` (Master-Daten, Exporte, Baukasten) ist per `.gitignore` ausgeschlossen und bleibt nur lokal.
